# Coachpilot

De app voor touringcarchauffeurs: busparkings met voorzieningen en reviews, hotels in de buurt op de kaart, en een open community.

## Status
Prototype (één bestand: `index.html`). Buiten Claude draait de app in **proefmodus**: accounts, berichten en foto's worden alleen op het eigen apparaat bewaard. De volgende stap is een echte backend (Supabase) voor inlog, database en foto-opslag, en Google Maps voor de kaart.

## Live zetten
Gekoppeld aan Vercel: elke wijziging op `main` gaat automatisch live.
